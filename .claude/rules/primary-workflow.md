# Primary Workflow

1. **Understand & Plan:** Read `README.md`, `AGENTS.md`, and relevant files in `docs/` to understand the architecture and problem context.
2. **Define Success Criteria:** Establish testable criteria before modifying code (e.g. regex test case, UI behavior, database migration).
3. **Execute Minimal Code Changes:** Apply surgical, minimal edits to target files only.
4. **Synchronize Documentation:** Update `docs/` when system contracts, architecture, or workflows change.
5. **Verify:** Execute `flutter test` and `flutter analyze` to guarantee zero regressions.
6. **Report:** Deliver a concise summary of changes, test outcomes, and any open considerations.
