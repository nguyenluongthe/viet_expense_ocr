# Documentation Management

- All project documentation lives under `./docs/`.
- Keep documentation in sync whenever:
  - Architecture or data models change.
  - New OCR recognition patterns or bank formats are supported.
  - New UI screens or components are introduced.
- Use clear markdown links with `file:///` format for absolute or relative navigation.
- Avoid duplicate or conflicting instructions across `AGENTS.md`, `CLAUDE.md`, and `docs/`.
